为当前工作区生成一份**短而有用**的规则文件 `.reizo/RULES.md`。Agent 每一轮都会读它，所以只写**读代码/文件看不出来**、又会影响做事方式的内容。

## 步骤

1. 先看现状：用 `list_dir` / `find_files` 了解结构；读 README、`package.json` / `pyproject.toml` 等清单、已有的 `AGENTS.md` / `CLAUDE.md` / `.reizo/RULES.md`（已有就在其基础上增补，不要覆盖）。办公类工作区（以文档、表格、PPT 为主）就看目录命名、模板和近期文件，判断它的惯例。
2. 提炼成规则草稿，**不超过 60 行**，中文为主，按需包含：
   - 这个工作区是做什么的（一两句）
   - 常用命令：构建 / 测试 / 运行（只写确认过能用的）
   - 命名与目录约定、哪些目录不要动
   - 文档 / 表格 / 演示稿的格式惯例（模板、字体、口径、单位、语言）
   - 交付习惯：产出放哪、文件怎么命名、需要先确认的事
   - 容易踩的坑（你在探索时发现的）
3. 不要写：能从代码直接读出的结构、通用编程常识、密钥或个人信息。
4. 把草稿完整展示给用户，用 `ask_user` 问一次：直接写入 / 我想先改改（自由输入修改意见）。
5. 用户确认后用 `write_file` 写入 `.reizo/RULES.md`。写完只说一句：规则已保存，之后每轮对话都会生效，可以随时手动编辑。
