# 画布性能复核（2026-10-03）

保留 Reizo 左侧 Agent、右侧画布的布局。本轮不使用模型、不调用收费接口、不写用户已有数据。使用本地隔离 API、真实 SQLite 和两份 1000 便签样本（0 连线 / 999 条链式连线）。生产构建由专用 QA 服务提供，只注入测试 API 地址和可见性能参考，未改生产产物字节。

## 已实现

| 改动 | 可验证结果 |
| --- | --- |
| 端口连接查询使用 XYFlow 的 connectionLookup | 2000 次查询约 3.2–3.4ms → 0.17–0.20ms；保留具体端口、无端口旧连线、方向及连接替换语义 |
| 图片编辑面板拖动查询改用 nodeLookup | 消除每次更新查找整个节点数组 |
| 图片/视频/音频/便签共用上游信息投影 | 1000 个目标、999 连线、仅位置变化：约 6.43ms → 0.238ms；1000 份输入信息引用均保持稳定，名称/拓扑变化仍更新 |
| 惯性滑动结束状态 | 复现过滑动停止超过 5 秒仍有 data-dragging=true；结束当前 coast 和真实 pointerup 时清除其所属平移标记，连续三次生产版手势后均恢复 false |

上游元数据使用不可变节点/边数组建立共享索引，保持未变化输入列表的引用。ImageNode 的编辑源查找也使用节点索引。位置变化不会迫使全部节点重算标签并重新渲染；来源改名、删除、跨会话以及不同媒体的原有默认名称有行为回归。

## 测量边界与结果

CPU 采样显示开发模式的 JSX/组件检查确有成本，因此补测 minified production build。帧率参考只覆盖实际手势，不把空闲 rAF 作为拖动结果。读取完整无障碍树会扰动主线程；本轮先等待拖动状态结束及采样完成，再获取该树。测试服务的指标及 preload shim 只在 QA 中存在。

1280×720、画布最大化、5% 总览、1000 便签/999 连线，每轮 F 恢复全景后执行同一平移。每个构建各三次，取中位数：

| 指标 | 修改前生产构建 | 最终生产构建 |
| --- | ---: | ---: |
| 手势 rAF 参考 | 16fps | 16fps |
| 手势 p95 参考 | 97.1ms | 103.0ms |
| ScriptDuration 增量 | 0.2880s | 0.2153s |
| RecalcStyleDuration 增量 | 0.2195s | 0.1556s |
| TaskDuration 增量 | 1.4594s | 1.2385s |

脚本/样式计算减少，但没有证据证明稳定的帧率跃升。该结果来自本机浏览器环境，不代替真实 Electron/GPU 或混合媒体验收；不得把查询函数的约 20 倍收益写成画布帧率提高 20 倍。

曾在同一生产候选中试验极低缩放隐藏便签文本，未观察到稳定收益，已经撤回。节点外观、内容、尺寸和连接保持；没有为了数字删去功能。此前隐藏缩略图、点阵和 inert 的尝试也未证明明显收益，不重复实施。

后端复核：1000 节点/999 连线快照中位数约 14.07ms、投影 1000 条变更约 0.45ms；5000/4999 分别约 87.81ms、1.57ms。这个开销主要在载入/变更时，不能解释每帧的全部绘制成本。

## 下一步优先级

1. **绘制与命中检测细分**：非脚本主线程开销仍占多数，需进一步 trace 区分 SVG 路径、透明命中区域、图层/栅格及复杂 DOM。真正的总览简化层需要保留选择、连接、键盘和节点定位语义，不能只减少显示数量。
2. **媒体缩略图与解码**：素材栏使用小尺寸显示原文件，图片节点也使用完整素材 URL。应测量真实 2K/4K 图片图的内存与解码，再建立按版本缓存的缩略图，保留编辑/导出的原文件。
3. **节点投影进一步局部化**：本轮已去除节点组件的全图上游订阅；CanvasPanel 的投影、布局吸附及边界跨入/跨出时的列表构建仍可进一步测量和限制更新范围。
4. **聊天与画布并行场景**：消息已有窗口化与 content-visibility；不要重复造虚拟列表。后续应测流式 Markdown/代码高亮与画布操作同时进行时的竞争，再决定合并增量或 worker。

## 复现与验证

- `node --import tsx scripts/canvas-handle-benchmark.ts`：连接查询及上游投影微基准，含几何变化引用稳定断言。
- `node --import tsx scripts/creation-preview.ts`：隔离 API；使用输出的临时 nonce 执行 `node scripts/canvas-perf-fixture.mjs <nonce> none 1000` / `chain 1000`，防止误种真实实例。
- `node scripts/canvas-perf-preview.mjs <production-output-directory>`：生产构建 QA，绑定 loopback 47161；与 Vite 预览互斥，不启动真实 Electron 数据目录。
- 受影响 6 个回归文件、42 项通过；类型检查及最终生产构建通过；相关 Lint 无错误，保留存量警告。
- 实际 UI 验证：上游名称显示、5% 选中后端口恢复、Enter 打开继续创作菜单、单节点拖动落库且保持 1000 节点/999 连线、连续平移结束状态复位。

只补了连接索引语义和输入投影稳定性两个必要行为检查，没有新增颜色、布局或 CSS 镜像单测。
