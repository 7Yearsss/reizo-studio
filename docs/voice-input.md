# 本地语音输入

首页和工作区输入框共用麦克风入口。点击后准备本地模型，首次需要下载约 80 MB；已有经过 SHA-256 校验的模型直接复用。允许麦克风权限后开始录音，说完再次点击麦克风或“结束录音并转文字”，结果追加到当前草稿，由用户检查后发送。

- 支持中文、英文；中文结果转换为简体。单次最多 120 秒，到时自动结束并识别。
- 录音面板显示时长和音量。Esc、取消、切换会话、隐藏窗口页面或卸载输入框会取消当前任务，停止麦克风并丢弃迟到的识别结果。
- 模型下载失败可重试；麦克风拒绝授权、设备缺失/占用、近乎静音、识别失败均有提示。
- 取消首次下载会关闭面板，但已经开始的模型缓存准备可能在本机后台继续。录音仅在模型准备完毕且获得麦克风权限后开始。

## 数据与运行环境

音频只保存在渲染进程内存，经 MediaRecorder 采集后转为单声道 16 kHz PCM，在专属 Worker 内通过 Transformers.js / ONNX WASM 执行 Whisper Base q8。没有音频上传接口，不将录音写入磁盘，也不调用聊天模型或云端语音 API。中文简繁转换字典随程序打包。

模型下载固定到 `src/shared/voiceInput.ts` 的版本和文件清单，逐文件核验长度和 SHA-256；落盘位置为 `<dataRoot>/models/voice/<revision>`。开发环境可从 `.cache/local-asr-models` 复用通过同样校验的模型。模型准备完成后可离线使用。

Worker 只从应用的 `127.0.0.1` API 读取模型及 WASM。Transformers.js 的 HTTP loader 指向本机，额外的 fetch 检查拒绝其他来源。运行资源使用该库配套的 ONNX 版本，通过 `scripts/prepare-voice-runtime.mjs` 随桌面包附带。Whisper 合并量化解码器使用 basic 图优化，避免当前 ORT extended QDQ 优化的兼容问题。

## 验证

针对性测试覆盖草稿保留、静音判断、模型校验与失败重试、模型准备并发、取消、会话切换、权限拒绝和迟到结果。

浏览器端到端验证使用本机生成的中文 WAV 作为测试媒体流，走真实 MediaRecorder、重采样、WASM 模型和草稿回填流程；没有开启实体麦克风。实体麦克风和系统授权仍需在用户设备实际试用。主进程新增语音路由，开发中的桌面客户端需要重启后生效。
