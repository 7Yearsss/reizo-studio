# TapNow 画布工作流实测笔记

> 调查范围：仅限 TapNow 画布编辑器的空间操作、节点操作、连线、动效和状态反馈。
> 
> 证据等级：`OBSERVED` 为登录后官方画布实测；`DOC` 为项目内 TapNow 规范描述；`TODO` 为尚未验证。

> 日期：2026-09-05。来源：用户已登录的 `https://app.tapnow.ai/canvas/...` 编辑器。使用真实鼠标/键盘交互、截图、可访问性树和只读 DOM 样式测量。当前样本为 1 个画布、4 个节点、3 条原始连线，主要为空媒体节点；不能代表所有模型、内容和缩放下的行为。当前记录不是逐帧录像，也未测得完整磁吸半径或帧率。

## 1. 已验证的画布结构

### 1.1 双栏共享工作区 `OBSERVED`

- 左侧为无限画布，右侧 Agent 对话持续存在。
- 画布节点和 Agent 对话在同一个项目上下文中，不通过页面跳转切换。
- 顶部提供画布名称、画布切换、返回工作空间和重命名入口。
- 左侧提供画布工具栏；底部提供导航、连线、网格、聚焦和缩放控制。

### 1.2 节点默认态与选中态 `OBSERVED`

- 默认节点保持低信息密度，只显示类型、标题、内容摘要和端点。
- 选中节点后，节点本体保持在原位置，生成输入面板在节点下方展开。
- 图片节点面板包含 Prompt、模型、画幅、清晰度、变体数量和生成按钮。
- 视频节点面板额外包含生成方式、画幅、清晰度和时长。
- 右侧 Agent 面板不会因节点选中而消失。

### 1.3 画布右键菜单 `OBSERVED`

在画布空白处右键后观察到以下菜单。此前有一次因视口移动而落在空白处，不能作为节点专属右键菜单证据：

- 上传
- 添加资产
- 添加节点
- 添加辅助工具
- 撤销
- 重做

### 1.4 多选与打组 `OBSERVED`

- 使用 `Shift` 点击可以追加选择节点。
- 多选后，选区上方出现独立工具条，当前观察到：`新建主体`、`打组`、`保存到素材库`、`反馈问题`。
- 点击“打组”会创建真正的 `group` 容器，内部节点仍保留为独立节点。
- 组容器上方工具条提供：`整组执行`、`创建模板`、`解组`。
- 组容器有自己的标题输入框，组和成员在 DOM 中是不同的 React Flow 节点。
- 拖动组容器后，组内图片和文本成员同步移动；组外视频和其他文本保持原位。
- 一次 `Ctrl+Z` 可恢复组容器及其成员的原始位置，说明组移动被记录为一个批量位置命令。
- 组外连线的重绘和跨组边界规则仍为 `TODO`。
- 点击“解组”会移除 group 容器，成员节点回到独立节点状态；原有 3 条画布连线仍保留。

## 2. 磁吸端点动效

### 2.1 视觉端点与真实 Handle 分离 `OBSERVED`

- 在约 49.26% 画布缩放下，真实 Handle 的 DOM 包围盒约为 2.96px，可见加号约为 11.82px。
- 外层容器为 80 个画布单位，当前屏幕包围盒约为 39.41px。容器大小不等于已验证的完整磁吸触发范围。
- 这让端点保持轻量，同时避免用户必须精确点击小圆点。

### 2.2 跟随与回弹 `OBSERVED`

- 鼠标进入端点附近后，加号沿指针方向偏移。
- 左右端点使用镜像逻辑。
- 接近端点时父容器约使用 `transform: translate(x, y)` 跟随指针。
- 接近过程观察到约 `250ms` 的快速跟随过渡。
- 离开后观察到约 `400ms` 的回弹过渡。
- 实测样式使用带轻微 overshoot 的 cubic-bezier，接近端点时更有弹性。
- 已证实是加号父容器发生位移；没有证据排除页面同时存在自定义光标。

## 3. 加号继续创作流程

### 3.1 点击右侧加号 `OBSERVED`

点击右侧加号后出现“引用该节点生成”菜单，而不是直接添加一个默认节点。菜单包含：

- 文本生成
- 图片生成
- 视频生成
- 图片编辑器
- 3D 生成

### 3.2 选择创作类型 `OBSERVED`

选择“文本生成”后观察到：

1. 新增文本节点。
2. 自动创建当前节点到新节点的连线。
3. 自动选中新节点。
4. 自动展开新节点的输入面板。
5. 用户可以直接继续输入下一步意图。

该流程可抽象为：

`当前节点 -> 选择下一种创作意图 -> 自动建点 -> 自动连线 -> 自动选中 -> 展开输入面板`

自动选中不等同于输入框获得键盘焦点，也不等同于视口自动居中。

### 3.3 拖向空白区域与左侧加号 `OBSERVED`

- 从节点右侧加号拖向空白区域，会打开同一个“引用该节点生成”菜单。
- 松手时保留落点附近的菜单和临时连线意图，不要求用户先手动添加节点。
- 此次拖线菜单通过点击外部取消，没有在这条路径选择类型；创建并连线仅在 3.2 的点击加号路径验证。
- 左侧加号已验证点击后打开“添加上下文”菜单；左侧拖向空白区域仍为 `TODO`。当前实测选项为：
  - 文本生成（生成或编辑文本）
  - 图片处理（生成或上传图片）
- 选择左侧“图片处理”后，新增图片节点并自动建立 `新图片节点 -> 当前节点` 的连线。

这形成了一个方向性规则：右侧加号用于继续生成下游结果，左侧加号用于补充上游上下文。

### 3.4 连接已有节点后的上下文面板 `OBSERVED`

- 将文本节点输出拖到已有图片节点后，图片节点生成面板出现一个文本上下文条目。
- 上下文条目显示来源类型和来源内容，可在生成面板中继续管理。
- 图片节点原本为空 Prompt 时，接入文本上下文后 `Generate` 按钮变为可用。
- 画布同时新增一条可访问的边记录：`Edge from text-... to image-...`。
- 这表明连线不只是拓扑关系，还会直接改变目标节点的可运行状态和输入 UI。

### 3.5 连线断开 `OBSERVED`

- 对测试连线执行右键动作后，截图观察到线附近出现圆形剪刀控件。出现究竟由悬停还是右键触发，仍需拆分验证。
- 点击剪刀只移除当前连线，源节点和目标节点都保留。
- 这是画布中的直接操作，不需要打开节点设置或右键菜单。

### 3.7 非法连接反馈 `TODO`

- 之前一次图片到文本的拖拽没有成功执行，不能作为非法连接证据。
- 当前画布原本就存在图片到文本的合法连线，因此不能据此推断图片到文本是否被拒绝。
- 非法连接的拖拽反馈、端口高亮、光标和回弹效果需要在没有既有目标边的干净节点上重新验证。

### 3.6 节点引用与 Prompt 来源条目 `OBSERVED`

- 目标节点可以把已连接来源插入为可点击的 `@Text` 引用胶囊。
- 引用胶囊保留来源类型和名称，不把来源内容粗暴复制成不可识别的纯文本。
- 来源条目支持单独预览原始内容。
- 连接关系和 Prompt 内引用是两个可区分的层次：前者改变图拓扑，后者改变当前生成请求的显式内容。

## 4. 节点编辑

### 4.1 双击编辑 `OBSERVED`

- 双击文本节点后，标题变为可编辑的 `textbox`。
- 节点正文变为富文本 `contenteditable` 区域。
- 同时会选中节点并展开节点自己的生成输入面板。
- 空文本正文显示“`双击开始编辑...`”类占位提示。
- 此次正文未输入测试文字，因此正文的失焦保存时机仍为 `TODO`；此前临时插入过图片 Prompt 引用，已清空还原。

### 4.2 标题编辑与数量选择 `OBSERVED`

- 选中图片节点后，标题可直接在 `请输入标题` 输入框中修改。
- 输入临时标题并切换到其他节点控件后，当前页面仍保留修改后的标题；刷新后的持久化尚未验证。
- 图片节点的生成数量菜单提供 `1×`、`2×`、`4×`。
- 选择 `4×` 后按钮变成 `Generate 4 variations`，当前画布仍为 4 个节点、3 条连线，没有立即派生四个分支。
- 当前模型的费用显示随后由 5 更新为 20。这只是生成前估价，没有提交生成任务。
- 因此该入口是生成数量配置，不能直接等同于规范中的“派生变体 ×4 并自动排布”。

### 4.3 生成面板缩放补偿 `OBSERVED`

- 画布缩放约为 `0.4926` 时，普通图片节点屏幕宽度约为 `123px`，其逻辑宽度仍为 `250`。
- 选中节点的生成面板屏幕宽度仍约为 `680px`，DOM 样式中观察到 `--float-scale: 2.0`，接近画布缩放的倒数。
- 因此生成面板会做反向缩放补偿，保持可读和可操作；它不是随节点一起无限缩小。
- 文档中“低缩放时所有节点坍缩成 36px 胶囊”的行为在当前样本中尚未观察到，不能直接照搬。
- 在最小缩放 `0.15` 实测：图片节点为 `37.5 x 37.5px`，加号约 `3.6px`，生成面板仍约 `680px` 宽，`--float-scale` 为 `6.6667`。卡片保持方形，未观察到胶囊化。此样本为空媒体，不能用于判断视频解码器卸载策略。
- 在最大缩放 `2` 实测：图片节点宽 `500px`，加号约 `48px`，生成面板仍约 `680px` 宽、`206.5px` 高，`--float-scale` 为 `0.5`。截图中面板因锚定在节点下方而落到视口外；DOM 存在不代表在屏幕上可操作。
- 滑块暴露范围为 `0.15` 至 `2`；键盘 Home 到最小档位，单次右箭头观察到增加 `0.01`。快速连续按键存在更新合并现象，不能简单按次数推算最终缩放值。

### 4.4 图片生成与结果回写 `OBSERVED`

- 提交一次低成本图片生成后，顶部积分从 `200` 降为 `195`。
- 生成中：模型、画幅和数量控件变为 disabled，生成按钮显示 `Generating...`。
- 生成完成后，结果回写到原图片节点，不新增结果节点，也不改变原有连线。
- 图片节点显示结果缩略图；右侧 Agent 对话仍保持原位。
- 选中已生成节点后，节点上方出现一组媒体操作按钮，具体语义需要逐项 hover 验证。
- 随后将生成数量切换为 `4×` 并提交同一 Prompt；顶部积分从 `195` 降为 `175`，实际扣除 `20`。
- 4× 完成后画布仍保持 4 个节点、3 条原始连线；没有创建 4 个独立图片节点，也没有新增 4 条连线。
- 图片节点内出现叠放的多张结果缩略图/卡片边缘，说明变体结果归属于同一节点的结果集合，而不是拓扑分支。
- 结果完成后生成按钮恢复为 `Generate`，模型、画幅和数量控件重新可用；同一节点可以再次发起生成。
- 当前已确认 4× 的结果集合视觉存在，但“如何逐张切换、下载、删除、设为当前版本”的按钮语义仍需逐项验证。

## 5. 撤销行为

### 5.1 加号创建结果 `OBSERVED`

- 加号创建节点和连线后，第一次 `Ctrl+Z` 观察到连线被撤销。
- 第二次 `Ctrl+Z` 观察到新节点被移除。

- 因此该动作当前表现为多个历史命令，而不是单次原子撤销。

此前创建的临时节点已撤销；本轮测试连线通过剪刀移除。恢复仅指当前图结构和测试 Prompt，不代表操作历史从未改变。

## 8. 动效实现证据

### 8.1 加号磁吸 `OBSERVED`

- 实际 Handle 是约 3px 的透明 React Flow 连接点。
- 可见加号约 12px；外层命中容器约为 80 个画布单位，随当前缩放换算为屏幕尺寸。
- 加号父容器使用 `transform: translate(x, y)` 追随指针。
- 接近端点时观察到约 `250ms` 的 `cubic-bezier(0.34, 1.8, 0.64, 1)` 跟随过渡。
- 离开端点后观察到约 `400ms` 的 `cubic-bezier(0.34, 1.56, 0.64, 1)` 回弹过渡。
- 过渡期间可以继续移动指针，动效不会锁住输入。

### 8.2 节点生成面板的展开 `OBSERVED`

- 选中节点后面板在节点下方展开，节点本体不被移入侧栏。
- 面板跟随节点位置保持空间锚定，但尺寸不能按普通节点等比例缩小理解。在画布缩放约 0.4926 时，DOM 上观察到 `--float-scale: 2.0300`，约为缩放倒数；图片面板屏幕宽度约 680px。多个缩放档位仍待实测。
- 面板展开后包含上下文条目、富文本 Prompt 区和生成参数条。
- 接入上下文后 Prompt 区上方增加来源条目，可访问性树标为 sortable；实际拖动重排未验证。

## 10. 当前收口状态 `OBSERVED / TODO`

截至本轮，已完成官方画布实测的主干交互：双栏空间、节点选中与浮动面板、左右加号语义、加号磁吸动效、自动建点连线、上下文引用、连线断开、多选打组、组移动撤销、缩放补偿、单图生成和 4× 结果集合生成。

4× 测试实际消耗 20 积分，余额由 195 变为 175；结果仍归属于同一个图片节点，未生成四个拓扑分支。这一事实修正了项目规范中“派生变体 ×4 自动排布为四个节点”的设计描述：该描述目前只能标记为 `DOC`，不能当作 TapNow 官方画布行为。

仍未能在当前登录样本中确认的画布能力包括：视频真实生成及抽尾帧接力、失败/重试状态、结果版本切换与删除、非法连接反馈和连接替换、多输入端口规则、左侧拖线到空白、组折叠为子图、Ghost Proposal 的真实落库边界、Agent 批量建点活动条。这些项目保留为 `TODO`，后续实现 Reizo 时应先做产品决策或安排独立验证，不能由规范文字推断为 TapNow 已有能力。
