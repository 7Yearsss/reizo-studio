# TapNow 创意画布全景工程落地规范
## 第 02 篇：核心节点分类与解剖规范 (Node Taxonomy & Anatomy)

> **版本**：v1.0.0  
> **面向对象**：前端核心开发、组件设计工程师、数据结构设计师  
> **核心目标**：定义画布中所有实体节点的物理骨架、端口契约、内部状态机与标准 TypeScript 数据模型。

---

### 1. 统一节点物理骨架契约 (Unified Node Anatomy)

所有业务节点必须基于相同的物理容器骨架构建，严禁各自发明异构布局：

```
┌────────────────────────────────────────────────────────────────────────┐
│ [Floating Action Bar: 派生变体 ×4 | 抽尾帧 | 存入作品库 | Agent 扩写]    │ (仅悬停浮现)
├────────────────────────────────────────────────────────────────────────┤
│ (● 输入端点 Target Handle)                  (○ 输出端点 Source Handle)  │
│ [🎬 图标]  镜头名称 (双击内联编辑)               [就绪 1080P] [⚙️滑块按钮]│ (统一 Header)
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│                                                                        │
│                       主 视 听 产 物 阶 段 (Stage)                      │ (Content Stage)
│             (视频海报带播放键 / 图片纯封面 / 交互波形播放器)             │
│                                                                        │
│                                                                        │
├────────────────────────────────────────────────────────────────────────┤
│ [“电影质感，雨夜霓虹倒影，推进运镜…”]                       [ ↻ 重新生成 ]│ (悬停底部提示词条)
└────────────────────────────────────────────────────────────────────────┘
```

#### 骨架区域职责划分：
1. **悬浮动作胶囊栏（Floating Action Bar）**：位于节点外部顶部上方 `-top-9`，鼠标悬停时平滑浮现，集中高频快捷操作。
2. **统一标题栏（Unified Header）**：
   - 左侧：节点类型专属微光图标（Lucide 图标）+ 标题（双击即时变更为 `<input>` 允许内联改名）。
   - 右侧：状态指示器（就绪绿色小点 / 生成中脉冲动画 / 报错红色感叹号）+ 滑块配置按钮（Sliders）。
3. **主视听阶段（Content Stage）**：占据卡片 80% 以上面积，纯粹呈现生成出来的多媒体成果。
4. **底部提示词窥视条（Bottom Prompt Peek）**：悬停时显示单行省略的 Prompt，右侧常驻一键重新生成（Regenerate）小按钮。

### 2. 六大实体节点深度解剖与工程规范

#### 2.1 文本 / 剧本节点 (Text & Script Node)

```
┌────────────────────────────────────────────────────────────┐
│ [● in_context]                                 [○ prompt_out]│
│ [📝 文本] 场景开场白与旁白台词                   [48 字] [⚙️] │
├────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 夜幕降临，雨水顺着霓虹灯招牌滑落。                       │ │
│ │ 侦探紧了紧风衣的领口，推开那扇吱呀作响的酒吧大门。     │ │
│ │ 吧台内，酒保正在擦拭一只沾满灰尘的威士忌酒杯…           │ │
│ └────────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────────┤
│ [✨ AI 视听扩写]                           [ 复制提示词 ]   │
└────────────────────────────────────────────────────────────┘
```

- **业务定位**：创意的起点、剧本台词的发源地、分镜提示词母本。
- **端口契约**：
  - 输入：`in_context`（接收上游大纲或角色设定，可选）。
  - 输出：`prompt_out`（翠绿色 `#4ade80`），可一条线同时连接下游多个分镜或音频节点。
- **专有交互**：
  - 大文本域自适应高度（最小 `120px`，最大 `360px` 内部滚动）。
  - 右上角显示实时字数/词数统计（影视台词按字数精确对齐秒数，如中文约 3.5 字/秒）。
  - 底部内置“✨ AI 视听扩写”按钮，点击后调用 LLM 一键把一句话大纲扩写为包含光影、景别、运镜的影视提示词。

#### 2.2 关键帧图片节点 (Image & Keyframe Node)

```
┌────────────────────────────────────────────────────────────┐
│ [● prompt_in]                                  [○ image_out]│
│ [● ref_anchor]                                             │
│ [🖼️ 图片] 概念原画：雨夜酒吧街角                [v3] [16:9] [⚙️]│
├────────────────────────────────────────────────────────────┤
│                                                            │
│               [ 高分辨率 1080P 渲染图片封面 ]                │
│                 (支持悬停 Lightbox 全屏预览)                │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ [ ◀ v1 | v2 | v3 ▶ ]                     [ 抽线生视频 ➔ ]  │
└────────────────────────────────────────────────────────────┘
```

- **业务定位**：概念美术、视频首帧（Start Frame）、图生图垫图。
- **端口契约**：
  - 输入：`prompt_in`（接收剧本文本）、`ref_anchor`（接收角色图钉约束）。
  - 输出：`image_out`（靛蓝色 `#818cf8`），可作为下游视频节点的“首帧”或“风格参考”。
- **专有交互**：
  - **空状态**：未生成时呈现优雅的拖拽/点击上传占位区，支持直接从桌面将本地图片拖入节点。
  - **历史版本轮盘 (Version Carousel)**：每次重绘不破坏历史，支持在底部左右切换历史生成的版本（`v1`, `v2`, `v3`）。
  - **Lightbox 放大**：点击图片弹出全屏高清灯箱，支持滚轮缩放与像素级审图。

---

#### 2.3 运镜视频节点 (Video & Camera Node)

```
┌────────────────────────────────────────────────────────────┐
│ [● prompt_in]                                  [○ video_out]│
│ [● start_frame]                                [○ end_frame]│
│ [● audio_in]                                   [○ audio_out]│
│ [🎬 视频] 镜头 01：推入酒吧推门特写           [Kling 3.0] [⚙️]│
├────────────────────────────────────────────────────────────┤
│                                                            │
│               [ 视频封面海报 + 中央微光播放键 ]             │
│            (悬停自动原地静音循环播放, 底部时间刻度)           │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ [ ✂️ 抽尾帧为新图片 ]                     [ 派生变体 ×4 ]   │
└────────────────────────────────────────────────────────────┘
```

- **业务定位**：视频生成核心单元，串联视听语言。
- **端口契约**：
  - 输入：
    - `prompt_in`（提示词 / 运镜指令，翠绿色）。
    - `start_frame`（首帧图片约束，靛蓝色）。
    - `audio_in`（背景配乐或旁白轨道，琥珀金）。
    - `ref_anchor`（角色面部锁定，紫罗兰）。
  - 输出：
    - `video_out`（成片视频流，洋红色 `#f43f5e`）。
    - `end_frame`（抽取出的尾帧图片，靛蓝色），用于动作接力。
    - `audio_out`（提取出的视频内置音轨，琥珀金）。
- **专有交互**：
  - **原地轻量播放器**：悬停时原地播放并显示播放进度细线，移出时重置回封面海报。
  - **一键抽尾帧**：悬停在底部点击“抽尾帧”，自动在当前节点右侧 `x + 360` 处生成新图片节点，并将 `end_frame` 连线至新节点。

#### 2.4 迷你音频播放器节点 (Audio Player Node)

```
┌────────────────────────────────────────────────────────────┐
│ [● prompt_in]                                  [○ audio_out]│
│ [🎙️ 音频] 旁白配音：侦探内心独白              [00:08 / 44kHz] [⚙️]│
├────────────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────────────┐ │
│  │ ❚❚  ◀◀  00:03 / 00:08             [ 🔁 单曲 ]  [ 🔊 ] │ │
│  ├───────────────────────────────────────────────────────┤ │
│  │ ▂▃▅▇█▇▆▅▃▂ ▂▃▄▅▆▇█▇▆▅▄▃▂ ▂▃▅▇█▇▆▅▃▂                   │ │
│  │ (可点击/拖拽波形瞬间跳转进度试听)                      │ │
│  └───────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────────┤
│ [ 拖拽音频文件替换 (MP3/WAV) ]               [ 导出音轨 ]   │
└────────────────────────────────────────────────────────────┘
```

- **业务定位**：语音合成（TTS）、配乐（BGM）、音效（SFX）。
- **端口契约**：
  - 输入：`prompt_in`（台词文本输入，用于 TTS 模型）。
  - 输出：`audio_out`（琥珀金 `#f59e0b`），直连视频节点的 `audio_in`。
- **专有交互**：
  - **ComfyUI / Runway 风格交互波形**：采用 Web Audio API 离线分析音频振幅，渲染 36 根柱状波形。
  - **点击拖拽跳转 (Click-to-Scrub)**：点击波形任意柱体，音频指针瞬间对齐并试听。
  - **小而全的控制台**：播放/暂停、后退 5 秒、循环模式切换、静音开关。

#### 2.5 角色与画风图钉节点 (Character & Style Anchor Node)

```
┌────────────────────────────────────────────────────────────┐
│                                               [○ anchor_out]│
│ [📌 图钉] 角色母本：林侦探 (强锁定)                [LoRA 0.85] [⚙️]│
├────────────────────────────────────────────────────────────┤
│  ┌───────────┐ ┌───────────┐ ┌───────────┐                 │
│  │   正面照   │ │   侧面照   │ │  服饰特写 │                 │
│  └───────────┘ └───────────┘ └───────────┘                 │
│  一致性权重锁定: [ ━━━●━━━━━ ] 0.85 (强一致性)             │
├────────────────────────────────────────────────────────────┤
│ [ 🧲 广播吸附到场景内所有镜头 ]            [ 新增参考视角 ] │
└────────────────────────────────────────────────────────────┘
```

- **业务定位**：彻底解决多镜头“角色变脸”与“风格漂移”。
- **端口契约**：
  - 输出：`anchor_out`（紫罗兰色 `#a78bfa`），具备**一对多广播特性**，连向后续多个镜头的 `ref_anchor`。
- **专有交互**：
  - 支持绑定角色的标准三视图（正脸、45 度侧脸、服饰配色卡）。
  - 提供一致性权重滑块（`0.0 ~ 1.0`）：
    - `0.3~0.5`（弱参考，仅参考发型与大体色调）；
    - `0.8~1.0`（强一致性锁定，严格对齐面部特征与五官比例）。
  - 点击“广播吸附”，自动将紫罗兰连线拉向当前框选大区内的所有视频镜头。

#### 2.6 场景大区分组与子图节点 (Section Group & Subgraph Node)

```
┌────────────────────────────────────────────────────────────┐
│ [● in_storyboard]                           [○ out_sequence]│
│ [🗂️ 场景大区] 场景一：雨夜酒吧初遇 (4 个镜头)       [收折为子图] [🔒]│
├────────────────────────────────────────────────────────────┤
│  (透明大框底板，内部包裹 4 个镜头节点)                     │
│  ┌─────────────┐   ┌─────────────┐   ┌─────────────┐      │
│  │ 镜头 1: 全景 │ ─►│ 镜头 2: 特写 │ ─►│ 镜头 3: 动作 │ ...  │
│  └─────────────┘   └─────────────┘   └─────────────┘      │
└────────────────────────────────────────────────────────────┘

               ▼ 点击 [收折为子图] 后，坍缩为芯片化单节点：

┌────────────────────────────────────────────────────────────┐
│ [● in_storyboard]                           [○ out_sequence]│
│ [🔲 场景子图] 场景一：雨夜酒吧初遇 (已折叠 4 镜头)   [双击展开编辑] │
├────────────────────────────────────────────────────────────┤
│  总时长: 00:16 | 产物: 1080P 4 镜头已串联 | 角色: 林侦探   │
└────────────────────────────────────────────────────────────┘
```

- **业务定位**：百级镜头长片项目的架构化管理底座。
- **专有交互**：
  - 半透明大框底板，拖拽边角可自由调整框选范围，框内的节点随大区整体移动。
  - 右上角提供锁死按钮（防止误拖）与“收折为子图”按钮。
  - 收折后，场景内所有中间连接线隐藏，卡片坍缩为一个芯片化的 Subgraph 节点，仅对外暴露起始输入与最终成片输出端口。

### 3. TypeScript 标准数据模型定义 (Data Models)

后续 AI 或前端工程师在实现状态存储时，应直接继承并实现以下接口规范：

```typescript
// 1. 概念模型与 Reizo Studio 实际底层数据库映射 (Reizo DB Enum Mapping)
// 注意：在 Reizo Studio 的 SQLite/Drizzle 数据库中，底层采用以下持久化枚举（完全向前兼容，无须危险迁移）：
export type CanvasNodeType =
  | 'image'             // 图片节点 -> Image / Keyframe
  | 'video'             // 视频节点 -> Video / Camera
  | 'audio'             // 音频节点 -> Audio Player (已就绪)
  | 'note'              // 文本节点 -> Text / Script (UI 呈现为大文本框，兼容历史便签)
  | 'anchor'            // 参考图钉 -> Character / Style Anchor (已就绪)
  | 'section'           // 场景大区 -> Section Group (已就绪)
  | 'subgraph'          // 子图节点 -> Subgraph (已就绪)
  | 'agent'             // 智能体卡 -> Agent Task
  | 'frame_extractor';  // 抽帧适配 -> Frame Extractor

// 2. 端口语义类型与句柄定义
export type SemanticPortType = 'prompt' | 'image' | 'video' | 'audio' | 'anchor' | 'control';

export interface CanvasPortHandle {
  id: string;                      // 唯一端口 ID，如 'audio_in', 'video_out'
  type: 'source' | 'target';       // 出/入
  semantic: SemanticPortType;      // 语义类型，决定连线颜色与连线校验
  label: string;                   // 端口中文提示
  multiConnect?: boolean;          // 是否允许多条连线接入（如 anchor_out 允许广播）
}

// 3. 运镜视频节点参数负载 (Video Node Payload)
export interface TapNowVideoParams {
  prompt: string;
  negativePrompt?: string;
  model: 'kling-3.0' | 'seedance-2.0' | 'sora-2-pro' | 'veo-3.1';
  aspectRatio: '16:9' | '9:16' | '1:1' | '2.35:1';
  durationSeconds: 5 | 10;
  fps: 24 | 30 | 60;
  
  // Cinema Lab 专业参数
  cinemaLab?: {
    cameraMovement: {
      pan: number;     // -10 到 +10 (水平摇)
      tilt: number;    // -10 到 +10 (俯仰)
      zoom: number;    // -10 到 +10 (推拉)
      roll: number;    // -180 到 +180 (旋转)
      curve: 'linear' | 'ease-in-out' | 'snap';
    };
    lensComboId?: string;       // 如 'arri-cooke-anamorphic'
    lightingPreset?: string;    // 如 'film-noir-rim'
  };

  // 生成状态与成果
  status: 'idle' | 'queued' | 'running' | 'completed' | 'failed';
  progress?: number;            // 0 到 100
  previewCoverUrl?: string;     // 封面海报图地址
  videoAssetUrl?: string;       // 生成成片地址
  extractedEndFrameUrl?: string;// 抽取的尾帧地址
}

// 4. 音频播放器节点参数负载 (Audio Node Payload)
export interface TapNowAudioParams {
  prompt?: string;              // 台词文本 (TTS)
  voiceId?: string;             // 音色 ID
  bgmStyle?: string;            // 配乐风格
  audioUrl?: string;            // 音频资源地址
  durationSeconds?: number;
  waveformSamples?: number[];   // 归一化后的波形数据数组 (0.0 ~ 1.0)
  loop: boolean;
  volume: number;
}

// 5. 角色图钉节点参数负载 (Character Anchor Payload)
export interface TapNowAnchorParams {
  characterName: string;
  avatarUrl: string;
  referenceViews: {
    frontUrl?: string;
    sideUrl?: string;
    costumeUrl?: string;
  };
  consistencyWeight: number;    // 0.0 到 1.0
  loraId?: string;
}
```
