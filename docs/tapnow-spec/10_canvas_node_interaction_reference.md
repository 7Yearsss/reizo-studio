# TapNow 画布节点操作逻辑参考

> 目的：把 TapNow 画布中可观察到的节点操作整理成 Reizo 可实现、可验收的交互契约。
>
> 证据边界：本文只把登录后画布实测记录标为 `OBSERVED`；项目规范或尚未复核的能力标为 `DESIGN/TODO`。截图只能证明当时的视觉状态，不能证明持久化或服务端事件。

## 1. 画布工作区模型

TapNow 是“无限画布 + 固定 Agent 面板”的双栏工作区。画布节点、连线和右侧对话共享同一项目上下文；选中节点、展开生成面板或缩放画布时，Agent 面板不会被替换或挤走。高密度画布仍保持拓扑视图，而不是自动切换到列表。

### 可见层级（OBSERVED）

1. 画布层：节点、端点、连线和媒体预览。
2. 空间工具层：Mini Map、隐藏连线、网格吸附、重置视图、缩放。
3. 节点操作层：选中态工具条、浮动生成面板、媒体控制。
4. Agent 层：建议卡、输入框、上下文添加、确认模式、发送和历史。

可访问性树还会把每条边暴露为 `Edge from <source> to <target>`，视频节点暴露播放、静音、时间滑块和全屏动作。这意味着实现时不能只给整张画布一个不可操作的标签；拓扑和媒体控制都需要独立语义。

## 2. 节点状态机

```text
idle
  -> selected                 单击节点
  -> editing                  双击文本节点
  -> generating               提交生成
  -> completed                结果回写
  -> failed                   生成失败（TODO：官方样本未复核）

selected
  -> idle                     点击空白或其他节点
  -> editing                  双击文本节点
  -> creating-downstream      点击右侧加号并选择生成类型
  -> adding-context           点击左侧加号并选择上下文类型
```

### 默认态与选中态（OBSERVED）

- 默认节点低信息密度：类型、标题、摘要和端点。
- 单击后节点留在原位，节点下方出现浮动生成面板。
- 图片面板包含 Prompt、模型、画幅、清晰度、变体数量和生成按钮。
- 视频面板还包含生成方式和时长。
- 选中节点不会让右侧 Agent 失焦或消失。

### 文本编辑（OBSERVED）

- 双击文本节点后，标题变成 textbox，正文变成富文本 `contenteditable`。
- 空正文显示“`双击开始编辑...`”类占位。
- 双击同时选中节点并展开生成面板，但不应假设键盘焦点自动进入正文。
- 正文失焦保存时机尚未复核，属于 `TODO`。

## 3. 端点与“继续创作”逻辑

端点有明确方向性：

| 端点 | 用户心智模型 | 菜单 | 创建后的连线方向 |
|---|---|---|---|
| 右侧加号 | 继续生成当前节点的下游结果 | 文本、图片、视频、图片编辑器、3D 生成 | 当前节点 -> 新节点 |
| 左侧加号 | 给当前节点补充上游上下文 | 文本生成、图片处理 | 新节点 -> 当前节点 |

### 点击加号（OBSERVED）

```text
点击端点
  -> 打开意图菜单
  -> 选择创作类型
  -> 新增节点
  -> 自动建立连线
  -> 自动选中新节点
  -> 展开新节点输入面板
```

自动选中不等于自动聚焦视口，也不等于输入框获得键盘焦点。

### 拖拽端点（OBSERVED/TODO）

- 从右侧加号拖到空白处会保留临时连线意图，并在落点附近显示同一菜单。
- 左侧拖到空白处尚未复核。
- 右侧点击路径已确认“建点 + 连线”；拖拽路径的类型选择和最终落点布局仍需单独验收。

## 4. 磁吸端点动效

- 真实 React Flow Handle 约 3px；可见加号约 12px；命中容器约 80 个画布单位。
- 指针接近时，加号父容器沿指针方向平移；左右端点镜像。
- 接近过渡约 250ms，离开回弹约 400ms，带轻微 overshoot，且可被新的指针移动打断。
- 位移应作用在可见加号父容器，不应改变真实 Handle 的拓扑位置。
- `prefers-reduced-motion` 下保留状态和颜色反馈，取消弹性和大范围运动。

## 5. 连线 = 拓扑 + 活上下文

连接成功后，目标节点不仅多一条边，输入面板也会增加来源条目。文本输出接入图片节点时：

1. 图片面板显示文本上下文条目。
2. 空 Prompt 的 Generate 变为可用。
3. 可访问性树新增 `Edge from text-... to image-...`。
4. 来源可以进一步插入为可点击的 `@Text` 引用胶囊。

因此实现应拆分两个层次：

- `edge`：图拓扑关系，可连接、断开、撤销。
- `sourceRef`：生成请求中的显式来源，可预览、移除、排序。

### 断开连线（OBSERVED）

- 连线操作态会出现圆形剪刀控件；当前样本尚未完全区分“悬停触发”还是“右键触发”。
- 点击剪刀只移除当前边，源节点和目标节点保留。
- 非法连接、连接替换、多输入端口和完整错误反馈仍为 `TODO`，不能从规范文字推断成已存在行为。

## 6. 多选、分组与撤销

### 多选和分组（OBSERVED）

- `Shift` 点击追加选择。
- 多选工具条出现：新建主体、打组、保存到素材库、反馈问题。
- “打组”创建真正的 `group` 容器，成员节点仍是独立节点。
- 组工具条提供整组执行、创建模板、解组。
- 拖动组容器时组内成员同步移动，组外节点不动。
- 解组移除容器，成员和既有连线保留。

### 撤销语义（OBSERVED）

加号创建节点的历史表现为多个命令：第一次 `Ctrl+Z` 撤销连线，第二次撤销新节点。组移动则表现为一次批量位置命令，可一次恢复组和成员位置。

这两类事实应在 Reizo 中显式区分：

- 用户意图型操作（组移动、批量删除、提案接受）记录为原子 batch command。
- 当前 TapNow 创建路径可能拆成 `CONNECT_EDGE` 和 `ADD_NODE` 两条历史记录；若 Reizo 合并，应作为产品决策而不是声称与 TapNow 一致。

## 7. 生成与结果归属

### 单图生成（OBSERVED）

- 提交后模型、画幅和数量控件 disabled，按钮显示 `Generating...`。
- 完成后结果回写原图片节点，不新增结果节点，不改变原有连线。
- 控件恢复可用，节点可再次生成。

### 4× 生成（OBSERVED）

- 数量菜单为 `1x / 2x / 4x`；选 `4x` 后按钮显示 `Generate 4 variations`。
- 4× 生成仍只保留一个图片节点和原有拓扑；结果以同一节点内的多结果集合/叠放缩略图呈现。
- 这不是“自动生成四个分支节点”。规范中的派生分支和自动排布目前只能标 `DESIGN`。
- 结果切换、删除、设为主版本尚未逐项复核。

## 8. 工程实现契约

### 8.1 事件时序

```text
pointerdown  -> 临时边/候选端口反馈
pointerenter -> 合法目标高亮或非法原因
pointerup    -> 确认动效 -> 写入 command/store
写入失败     -> 回滚临时边 -> 显示原因
```

### 8.2 必须保持的空间关系

- 浮动面板锚定节点下方并做反向缩放补偿；不能把参数面板搬成固定侧栏。
- Agent 面板宽度和位置稳定；画布交互不应抢走 Agent 输入焦点。
- 节点、连线、媒体控制、Mini Map 和缩放工具均应有独立可访问性语义。

### 8.3 验收清单

- [ ] 单击节点：节点保持位置，面板展开。
- [ ] 右侧加号：菜单 -> 新节点 -> 下游边 -> 新节点选中。
- [ ] 左侧加号：菜单 -> 新节点 -> 上游边 -> 当前节点。
- [ ] 文本接图片：来源条目出现，空 Prompt 可生成。
- [ ] 连线断开：只删边，不删节点。
- [ ] Shift 多选、打组、组移动、解组和撤销。
- [ ] 0.15x、0.5x、1x、2x 下节点和面板仍可操作。
- [ ] 图片 1x/4x：结果归属同一节点，生成中控件禁用。
- [ ] 非法连接、替换、多输入、失败重试：当前官方样本尚未覆盖，需单独标记测试结果。
